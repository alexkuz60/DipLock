# Инвентарь тестов: что уже покрыто

## Статические проверки: ruff + mypy + CI

Кроме тестов изменение обязано проходить два статических входа (конфиг — `backend/pyproject.toml`,
исключений «на глаз» в конфиге нет — каждое подписано причиной):

```bash
cd backend && venv/bin/ruff check app tests scripts alembic  # линтер
cd backend && venv/bin/mypy app alembic                      # типы (check_untyped_defs = true)
```

Набор правил ruff — осознанный, а не «всё включено»: `E4/E7/E9/F` (pycodestyle+pyflakes), `I`
(isort), `UP` (синтаксис python 3.12: `X | None`, `dict[str, int]`, `type X = …`), `B` (bugbear),
`SIM`, `RUF`, `ASYNC` (блокирующий I/O в `async def`), `S` (bandit). Исключения:

* `B008` — `Depends()`/`Query()` в значениях по умолчанию: норма FastAPI;
* `B019` — LRU-кэши на уровне модуля: осознанный приём проекта (`docs/rules/data-and-caches.md`);
* `RUF001–003` — «неоднозначные» юникод-символы: тексты проекта на русском, кириллица здесь норма;
* `ASYNC240` — `os.path`/`stat` в async-обработчиках раздачи статики: микросекундные операции,
  долгие файловые операции по-прежнему запрещены (их ловит `ASYNC230` — конвенция «Async» в `AGENTS.md`);
* per-file: `tests/**` — `S101` (assert — инструмент pytest), `tests/conftest.py` — `E402` (каталоги
  данных уводятся в tmp **до** импорта настроек), `tests/test_api_contract.py` — `S108` (тесты путей),
  `scripts/**` — `S101`/`T201` (печать — часть CLI-скрипта).

`mypy` намеренно мягкий к отсутствующим стабам (`ignore_missing_imports`, научный стек) и строгий к
телам: `check_untyped_defs = true`. Ожидаемое состояние — **0 ошибок**; «подавить» их допустимо
только точечно и с пояснением (`cast` для `nib.load`, `# noqa` для `hashlib.sha1` в ключе RAM-кэша).

CI — `.github/workflows/ci.yml`: job `backend` (`ruff` → `mypy` → `pytest -m "not integration"`) и
job `frontend` (`npm run lint` → `gen:api` + `git diff --exit-code` (свежесть `schema.d.ts`, 4.2) →
`typecheck` → `test` → `build`). Локально те же команды, поэтому
«зелёный CI» проверяется без пуша. Инструменты лежат в `backend/requirements-dev.txt`.

**Правило (зависимости):** всё, что приложение импортирует на старте (`app/models/db.py`
создаёт движок БД на импорте), заявляется **явно** в `backend/requirements.txt`, а не берётся
транзитивно из локального venv — чистое окружение CI этого не видит и падает только там
(F3 — `aiosqlite`; 26.09.2026 — `greenlet` через extra `sqlalchemy[asyncio]`). Оба объявления
закреплены `backend/tests/test_requirements.py`.

**Правило:** рефакторинг без изменения поведения начинается с этой страховки — сначала зелёные
линтер/типы/тесты, потом правки, и после каждого шага прогон заново. Именно так поймано то, что
автофикс ruff удаляет импорты-реэкспорты: потребителя в тесте видно только по запуску тестов.
