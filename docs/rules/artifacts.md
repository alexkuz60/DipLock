# Артефакты ЭЭГ: каталог видов, правило BAD_, QC и MNE-only-очистка

> Правило поиска, чисел QC и базового удаления артефактов. Источник критериев —
> PDF «Артефакты ЭЭГ» и стратегия `docs/strategy/01-signal-quality.md`.

## Каталог видов (11) и правило BAD_

`ArtifactKind` (`schemas/analysis.py`) = `ARTIFACT_KINDS` (`shared/lib/artifacts.ts`) =
ключи `artifact_types` (открытый словарь `dict[str, int]` — новый детектор не ломает контракт):

| reject-виды (роняют эпохи) | информационные (зоны UI/QC, эпоху не трогают) |
|---|---|
| `zscore_outlier`, `peak_to_peak`, `flat_line`, `clipping`, `break`, `electrode_pop` | `muscle_emg`, `line_noise`, `ocular`, `ecg`, `ica_eog` |

**Правило BAD_** (`artifact_detector.EPOCH_REJECT_KINDS`, докстринг модуля):
аннотации с префиксом `BAD_` (и только reject-виды) попадают в raw и роняют эпохи
через `reject_by_annotation` (N6). Информационные виды в аннотации **не попадают
вовсе** — инвариант держит `test_bad_rule_annotations_only_reject_kinds`.
Добавили вид — пополнили `ANNOTATION_DESC` (только если reject) и каталоги выше.

**Amplitude reject MNE отключён** (23.09.2026, `reject=None` в `epoch_segmenter`): эпохи
отбраковываются **только** через `BAD_` — адресно (тип, канал, время зоны); порог амплитудного
reject удалён из всего стека (config → services → API → schemas → UI). Следствие для контракта:
`rejected_epoch_channels` (`EpochRejectOut`) собирается из `drop_log`, но списки каналов **всегда
пустые** — `drop_log` несёт причины (`BAD_…`, `TOO_SHORT`/`NO_DATA`/`USER`), а не имена каналов;
рамки `epoch-frame` не рисуются. «Все эпохи отброшены» — ошибка «Все эпохи отброшены
аннотациями BAD_» с **покрытием по типам** (`segment_epochs.bad_coverage_text`, фидбэк
24.09.2026): «zscore_outlier — 92 % записи (43 зон), …» — чтобы «кто занял запись» было видно
в тексте ошибки, а не выяснялось по слоям вьюера.

## Детекторы (MNE/NumPy/SciPy only, без новых зависимостей)

* `zscore_outlier` — robust z (медиана/MAD, M11): выброс не тянет порог за собой;
* `peak_to_peak` — размах в окне 2 с (геометрия зоны историческая — центр окна);
* `flat_line` / `clipping` — размах в окне `flat_line_window_ms` < порога: у края
  диапазона канала (доля отсчётов у rails ≥ `clipping_share`) — клиппинг, иначе —
  плоская линия (PDF: «эпизоды клиппинга» отделены от «нулевой активности»);
* `break` — NaN/inf-участки длиннее `break_min_duration_ms` (покрывает смысл N10
  `annotate_nan`/`annotate_break`: MNE ищет NaN-сегменты и пропуски между блоками
  **событий**, для монолитных EDF без событий `annotate_break` пуст; наш детектор
  ловит разрывы данных без событий);
* `electrode_pop` — ступенька ≥ `pop_step_uv` с возвратом ≤ 0.5 с;
* `muscle_emg` — `mne.preprocessing.annotate_muscle_zscore` **по каналу** (MNE
  усредняет z-power по монтажу и пропускает локальный всплеск); короче
  `muscle_min_duration_ms` — не эпизод;
* `line_noise` — свой Welch-PSD: канал помечается по **основной** гармонике
  50/60 Гц (пик/фон ≥ `line_noise_ratio`), зоны — по загрязнённым гармоникам
  1…4; `stats["line_noise_level"]` — максимальное отношение пик/фон (QC);
* `ocular` — медленные волны Fp1/Fp2 (прокси EOG), robust z сглаженного 200 мс;
* `ecg` — QRS-пики T7/T8 (5–20 Гц), ритм подтверждается по IBI;
* `ica_eog` — `run_ica` стадии `artifacts` **ищет** EOG-компоненты (счётчик
  `by_type.ica_eog` — их число, для остальных видов счётчик = числу зон); **зон не
  создаёт вовсе** — компоненты не привязаны ко времени (фидбэк 24.09.2026, см.
  «ICA: достижимость»); поиск идёт по EOG-каналам записи либо фронтальному прокси
  Fp1/Fp2 (см. «ICA: достижимость» ниже).

Пороги — из `core/config.py` (в `/meta` → `artifact_thresholds`); стадия передаёт
детектору копию конфига со своими значениями (`preprocess._detect`).

## Числа QC (стадия `artifacts`)

`qc_summary`: `good_data_percent` (100 − средняя по каналам доля времени в зонах
`QC_TIME_KINDS`; `ica_eog`/`line_noise` не считаются временем), `artifact_share_by_kind`,
`line_noise_level`, `bad_channels` (авто: robust z «шумности» канала + мёртвые
константы, `find_bad_channels`), `snr_db`/`snr_db_min` (медиана/минимум SNR
каналов) и `dead_channels` (шаг 2.2, см. ниже). Панель — плашки в легенде
артефактов; авто-список bad-каналов и мёртвых кнопками подставляются в опцию
интерполяции.

## QC-светофор записи и мёртвые каналы (шаг 2.2/N10)

* **SNR канала** (`channel_snr_db`) = `10·log10(P(2–30 Гц) / P(30 Гц…Найквист))`
  по Welch-PSD: ритмические полосы δ…β против высокочастотной шумовой полки
  (мышечный/аппаратный шум). Грубая QC-оценка, не классический SNR; при band-pass
  подготовке (h_freq ≤ 40) верх спектра подрезан — цифра оптимистична, честнее
  сравнивать записи «Без фильтра». Строка `channel_qc` несёт `snr_db` и `dead`.
* **Мёртвые электроды** (`find_dead_channels`) ищутся **до референса** в
  `load_edf`: средний референс маскирует константный канал («−средним остальных»),
  flat-line его не видит (стратегия `01-signal-quality` §2 п.1). Найденные
  помечаются в `info['bads']` механизмом MNE; `apply_cleaning` объединяет их
  с bad-каналами формы (не перетирает), `interpolate_bads(reset_bads=True)`
  сбрасывает список ровно когда мёртвый канал исправлен.
* **Вердикт светофора** (`record_qc_status`) — худший из четырёх категорий
  (`ok < warn < bad`) с причинами для тултипа: чистые данные %, сетевой шум
  (пик/фон), SNR-медиана, плохие каналы (авто ∪ мёртвые). Пороги — `qc_*` из
  `core/config.py` (ручки владельца; числа уточнятся с реальными записями —
  стратегия §14). В UI — пилюля «Светофор» в легенде артефактов панели EDF;
  иконки каналов (`channelQcStatus`) учитывают SNR и мёртвый канал наравне с
  долей времени в зонах.

## Очистка (стадия `filter`, MNE-only)

Параметры очистки — стадия `filter` (`PreprocessParams`/форма): `notch_harmonics`,
`bad_channels`, `interpolate_bads`, `clean_method: none | ica | ssp`,
`ica_n_components` (0 — auto). Золотой порядок (`services/artifact_cleaner.py`,
PDF «используйте интерполяцию после поиска плохих каналов и до ICA/SSP»):

1. гармоники notch (50/60 → 100/150/200/240 Гц);
2. пометка bad-каналов; 3. **их интерполяция**;
4. `ica.apply` (удаление EOG/ECG-компонент, прокси T7/T8; отчёт — сколько и какие)
   либо SSP (`compute_proj_eog`, **экспериментально**, UI предупреждает: проекторы
   необратимы). Отчёт «до/после» — p95 |x| по монтажу (`CleanReportOut`).

Вне скоупа: ASR (`asrpy`), `autoreject`, `mne-icalabel` (N12/N13) — новые
зависимости не добавляем.

## ICA: достижимость (N8, шаг 2.1, закрыт 24.09.2026)

Обе ICA-ветки (детекция `run_ica`, очистка `clean_method: ica`) живут общими
хелперами `artifact_cleaner`:

* **сканирование EOG-компонент** (`find_eog_component_inds`): нативно — EOG-каналы
  записи, их нет (N8: `load_edf` делает `pick` только по каналам 10-20) —
  фронтальный прокси `FRONTAL_PROXY` (Fp1/Fp2/FPz, `find_bads_eog(ch_name=…)`).
  Прокси-фолбэк идёт явной корреляцией `measure='correlation'` с порогом
  `_PROXY_CORR_THRESHOLD=0.5`: дефолтный z-score MNE (3.0) при малом числе
  компонент не срабатывает даже на корреляции −0.999 (замер 24.09.2026,
  6 компонент → z ≈ 2.1). Ни EOG-каналов, ни фронтальных — честное
  `RuntimeError` → предупреждение, а не падение задачи;
* **фитинг** (`fit_ica`): на high-pass-копии `raw.copy().filter(1.0, None)`
  (MNE требует HP ~1 Гц), `ica.apply` — на исходном сигнале (рецепт MNE
  «fit filtered, apply original»); исходный raw не фильтруется и не мутируется;
* **метод — fastica**, ему нужен `scikit-learn` (`requirements.txt`): без sklearn
  `ica.fit` падал ImportError, и ошибка глоталась в warning (ветка была мертва
  всегда, а не только без EOG-каналов);
* **достижимость из UI**: чекбокс «Искать EOG-компоненты ICA» панели «Пороги
  артефактов» (`runIca`, стадия `artifacts`, default false) — правка параметра
  расчёт не запускает;
* **зона `ica_eog` не создаётся** (фидбэк 24.09.2026): компоненты EOG не привязаны
  ко времени, а полоса «на всю запись» перекрывала вьюер и читалась как блокировка
  нарезки. Наружу — только счётчик `by_type.ica_eog` (число компонент) и
  `ica_applied`; в легенде вьюера ICA — информационный чип без тумблера слоя,
  число берётся из `artifact_types` стадии. В панели «Видимость артефактов»
  чекбокса `ica_eog` нет — скрывать нечего.

## Границы и кэш

* Очистка входит в ключ кэша подготовленного сигнала (`CleanSpec`, N5/A4):
  очищенный сигнал кэшируется отдельно, стадии `artifacts`/`epochs` с теми же
  параметрами получают его же.
* Спектр, спектрограмма и быстрый расчёт диполей вызывают `prepared_raw` **без**
  `clean` — они считаются на неочищенном подготовленном сигнале (граница задокументирована,
  расширение — отдельная задача).
* MNE API дрейфует: `annotate_muscle_zscore` в MNE 1.13 отдаёт **кортеж**
  (аннотации, scores), `ICA(random_state=...)` — именованный аргумент (см. также
  `docs/rules/safety.md`).
