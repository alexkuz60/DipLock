## 1. Принципы и ограничения

| Принцип | Реализация |
|---|---|
| Только десктоп, без мобильного адаптива | `min-width: 1366px` на `body`, `height: 100vh`, скролл только внутри рабочих областей |
| Тёмная тема | Токены Tailwind v4 в `frontend/src/styles/index.css` (`--color-bg-*`, `--color-fg-*`, `--color-accent`) |
| Крупный шрифт, системный для ОС | `system-ui, -apple-system, "Segoe UI", Roboto, Ubuntu…`; базовый кегль 16/18/20 px (переключатель в «Настройках»), цифры — `tabular-nums` |
| Крупные иконочные кнопки с тултипами | `IconButton` + Radix `Tooltip` (задержка 300 мс, доступ по фокусу с клавиатуры, есть `aria-label`) |
| Три зоны | Левый рейл 72 px (навигация) · центр: тулс-хедер + рабочая область + статусбар · правый сайдбар 384 px (схлопывается в 48 px) |
| Хоткеи | `1…9` — разделы, `[` — панель опций; обработчик игнорирует ввод в полях |
| **Обработка — только по кнопке** | Правка параметра никогда не запускает расчёт: параметры складываются в состояние раздела, кнопка действия становится доступной, UI показывает «параметры изменены — результат не пересчитан». Расчёт стартует исключительно по нажатию кнопки: сначала параметры и визуализация, обработка подключается к уже готовому UI |
| Ссылка воспроизводима (3.2б) | Общие параметры живут в URL: `?rec=` (запись), `?band=` (полоса фильтра диполей), `?slice=` (срезы MNI); раздел — в пути. Правка параметра дописывает URL через `replace`, но не запускает расчёт; отсутствие параметра = дефолт, мусор игнорируется |
| Долгие операции | Только через job-API (`POST /api/v1/jobs`), прогресс по этапам, индикатор активных задач в рейле; отмена из UI — `DELETE /api/v1/jobs/{id}` (кооперативная: воркер останавливается на ближайшем тике, статус `cancelled`, кнопка «Отменить» у прогресса, 3.2); перед запуском дорогой операции показывается оценка стоимости |

## 2. Карта экранов

| # | Раздел | Назначение | Тулс-хедер | Правая панель | Статус |
|---|---|---|---|---|---|
| 1 | **Главная** (`/`) | Заставка-название по центру, строка готовности, быстрые действия | нет | нет | готово |
| 2 | **EDF** (`/edf`) | Просмотр записи: треки ЭЭГ, зоны артефактов, границы эпох, предподготовка | да (действия, стадии, паспорт, листание окна, зум, слои) | да | действия шапки + вьюер на реальных сигналах, стадии и слои из результата (срезы 2.2–2.11) |
| 3 | **ЭЭГ** (`/eeg`) | Один канал: сырой трек сверху, спектрограмма снизу, общая ось и курсор, метки точки клика | да (канал/микс, расчёт-иконка, зум/листание, амплитудный зум) | да | трек на реальных сигналах, спектрограмма STFT по кнопке, линейки значений, нулевая линия и линия уровня, рамка окна трека в «обзоре», разделитель, режимы «связано/обзор», переход из EDF по названию канала (срез 5), виртуальные каналы-миксы (все каналы, полушария, области) и слои артефактов из EDF на обеих половинах (срез 5+), лог-шкала частот и режим ERD/ERS % от baseline — параметры просмотра (шаг 2.4, N18) |
| 4 | **Диполи** (`/dipoles`) | Запуск расчёта, 3 проекции мозга, playback траектории | да | да | три проекции (SVG) со слоями, срезы кликом и линейкой, точка/перекрестие (срез 3.1), реальный срез МРТ (3.2), быстрый расчёт по кнопке и спектр в выдвижной панели (3.4) с выбором метода PSD Welch/multitaper и разложением 1/f + пики (шаг 2.4); точный профиль и playback — далее |
| 5 | **Таблица** (`/table`) | Таблица локализации (MNI, амплитуда, GOF, BA), экспорт | да | да | все точки результата, сортировка по эпохе и состав колонок (срез 4); фильтры, виртуализация и экспорт — далее |
| 6 | **Групповой анализ** (`/group`) | Записи из БД: групповые фильтры, агрегаты по BA, поиск закономерностей | да | да | каркас + заглушка |
| 7 | **Итоги** (`/summary`) | Переключатель «Отчёт»: сквозной автоотчёт записи (QC и препроцессинг — часть 1, MNE.Report + пакет диполей по полосам с динамикой структур/BA — часть 2) и два отчёта группового анализа — **Тип 1 «Сравнение»**, **Тип 2 «Группа»** (§3.9.8) | да (сборка, прогресс, отмена, открытие HTML; групповые — сборка/открытие) | да (полосы пакета, шаг сетки; групповые — выбор источника из истории) | задача `kind=report` → iframe HTML-ассета; групповые — ленивый `GET …/report` (срез 03.10.2026, `docs/ui/summary.md`) |
| 8 | **ЕмоЛаб** (`/emolab`) | Психоэмоциональный фон: маркеры и их динамика | да | да | каркас + заглушка (срез 01.10.2026) |
| 9 | **Нейроаудио** (`/neuroaudio`) | Ответ на аудиостимуляцию: события, осцилляторный ответ, локализация | да | да | каркас + заглушка (срез 01.10.2026) |
| 10 | **Нейромузыка** (`/neuromusic`) | ЭЭГ → звук: 7 треков полос ×32/×64/×128 (выбор октав) + мастер, плеер и партитура (эксперимент) | да | да | рендер, статус, WAV/sidecar (фаза 1, `docs/rules/neuromusic.md`) |
| ⚙ | **Настройки** (`/settings`) | Масштаб текста, плотность, параметры расчёта (read-only из `/meta`), модельный роутер ИИ (провайдеры API моделей) | да | нет | готово |
| 🖥 | **Состояние сервера** (`/server`) | Проверки готовности, версии, пути, параметры расчёта, поллинг 5 с | да | нет | готово |

Раздел 6 (групповой анализ) и разделы 8–9 (ЕмоЛаб, Нейроаудио) пока показывают
плейсхолдер с планом работ — это осознанный шаблон: новый раздел = запись в
`frontend/src/app/sections/registry.ts` + компонент в `routes.tsx`.
Раздел 7 («Итоги») работает с среза 01.10.2026 — спецификация в
`docs/ui/summary.md` (§3.9).
