1. Жёсткий порядок: Шаг 2 → Шаг 3 (С0 ✅ → С1 → С2, затем С8); Шаг 4 — параллельный трек.
   Каждый шаг = тест (backend → pytest, frontend → Vitest); N6/N7/N20 — регрессионные
   инварианты. Производительность — **сначала замер** (`journal`/`analytics.db`), потом правка.
2. Новые кэши/хранилища → строка в `docs/data_map.md`; длинные правила → `docs/rules/`;
   закрытое из этого файла → `docs/history.md` (дословно).
3. Сознательно отложено (журнал решений): autoreject — отклонён, `mne-icalabel` — вторая
   advisory-разметка ICA (спайк 01.10.2026); Parquet/DuckDB/Zarr — с 4.7; connectivity/PAC —
   после 2.7; самописный 3D — против Niivue (25.09.2026); перенос вычислений на клиент
   (C1/C2) — отклонён по замерам.
4. **Дипольный пакет — межполосное сравнение** (25.09.2026): число прогонов по узким
   поддиапазонам решает нейрофизиолог по качеству EDF/артефактов/спектра; **GOF между

   eLORETA-карты и LCMV в пакет не тащить. Правило — `docs/rules/dipoles.md`.
